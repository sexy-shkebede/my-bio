Yandex Station Extended¶

Открытая вики о том, как получить доступ к умным колонкам Яндекса и что с ними можно сделать дальше: SSH, свой софт, USB-периферия, AirPlay, свои звуки. Всё — для своих устройств.

Чат сообщества в Telegram
Находки, новости и обсуждение проекта — в @hackalice.

Открыть чат

С чего начать¶

  1. 1
    Получение root — у каждой модели свой способ, без разборки (~15 минут).
  2. 2
    SSH и отключение обновлений — чтобы доступ не пропал.
  3. 3
    Пакеты yse — htop, tmux, nano, python и тысячи других.
  4. 4
    Если что-то сломалось — диагностика и откат.

Разделы¶

  • Начало работы

    Root, SSH, защита от обновлений, пакеты, восстановление.

  • Рецепты

    USB Host (флешки, Ethernet, наушники), AirPlay, свои звуки, Fastfetch, подсветка, плагины YAM.

  • Устройства

    Железо каждой модели: SoC, флеш, I2C, звук, подсветка.

  • Как это устроено

    Прошивка quasar, сеть и порты, подводные камни, сборка своего софта.

Модели¶

Модель Способ получения root
Мини 2, Миди, Станция 2, Стрит, Умный хаб подмена DNS
Лайт (1-го поколения) подмена DNS; на сборках после 21.10.2026 — свой сервер обновлений с откатом прошивки на .46
Лайт 2 (Plum) сертификат из factory-образа
Мини 3 (bergamot) сертификат и маркеры из factory
Мини 1 (2019, YNDX-0004) свой образ по USB — без сброса и смены DNS
Станция 3 (orion) подмена DNS; свой сертификат колонка не примет
Станция 1-го поколения AliceBridge с Android-телефона
Станция Макс (YNDX-0008) доступ по ADB: права действуют до перезагрузки
JBL Link Music (с Алисой) ADB по USB на старте
Мини 3 Про (pickle) только на заводской factory-12 — подмена DNS
Совпадений не найдено. Попробуйте сбросить фильтр.

Все способы проверены на живых колонках. Подробности по каждой модели — в каталоге устройств.
